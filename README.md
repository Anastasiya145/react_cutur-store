Welcome to Cutur Store! This is a modern e-commerce application built with React and TypeScript. It features a complete shopping experience with user authentication, shopping cart, wishlist, and order management. The application is designed to provide a seamless online shopping experience for mobile phones and accessories. ## 🚦 Getting Started

### Prerequisites

```bash
Node.js >= 18.0.0
npm >= 9.0.0
````

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/Anastasiya145/react_cutur-store.git
cd react_cutur-store
```

2. **Install dependencies**

```bash
npm install
```

3. **Start development server**

```bash
npm start
```

The application will open at `http://localhost:3000`

### Available Scripts

```bash
npm start          # Run development server
npm run build      # Build for production
npm test           # Run tests
npm run lint       # Run ESLint
npm run deploy     # Deploy to GitHub Pages
```

## 🎨 Design Principles

### **Component Architecture**

- **Atomic Design** - Building from atoms to organisms
- **Composition over Inheritance** - Flexible component reuse
- **Single Responsibility** - Each component has one job
- **Props-driven** - Configurable and predictable behavior

### **Code Quality**

- **TypeScript First** - Type safety throughout
- **Functional Components** - Modern React patterns
- **Custom Hooks** - Reusable stateful logic
- **Error Boundaries** - Graceful error handling

### **Styling**

- **BEM Methodology** - Clear, consistent naming
- **SCSS Modules** - Scoped styles
