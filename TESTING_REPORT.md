## Пользовательские команды

### Реализованные команды в commands.ts:

#### 1. cy.login(email, password)

```typescript
cy.login("user@example.com", "password123");
```

Автоматизирует процесс входа пользователя в систему.

#### 2. cy.logout()

```typescript
cy.logout();
```

Выполняет выход пользователя через меню.

#### 3. cy.addToCart(productId)

```typescript
cy.addToCart("iphone-15-pro");
```

Добавляет товар в корзину по ID.

## Рекомендации по улучшению

### Для лучшей надежности тестов:

1. **Добавить data-cy атрибуты к ключевым элементам**

   ```tsx
   // В Header.tsx
   <div data-cy="cart-icon">...</div>

   // В кнопках
   <button data-cy="submit-button">...</button>

   // В формах
   <input data-cy="email-input" name="email" />
   ```

2. **Использовать data-cy вместо классов**

   ```typescript
   // Вместо
   cy.get(".header__cart-icon");

   // Лучше
   cy.get('[data-cy="cart-icon"]');
   ```

3. **Добавить больше E2E сценариев**
   - Полный путь: Выбор товара → Корзина → Оформление → Подтверждение
   - Тестирование ошибок API
   - Тестирование пограничных случаев

4. **Интеграция с CI/CD**
   - GitHub Actions для автоматического запуска тестов
   - Генерация отчетов о покрытии
   - Скриншоты и видео при падении тестов
