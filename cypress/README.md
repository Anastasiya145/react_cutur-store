# Cypress Tests - React E-commerce Application

Этот проект покрыт E2E (End-to-End) тестами с использованием Cypress.

## Установка Cypress

Сначала установите Cypress:

```bash
npm install --save-dev cypress
```

## Запуск тестов

### Открыть Cypress Test Runner (интерактивный режим)

```bash
npm run cypress:open
```

Это откроет интерактивное окно Cypress, где вы сможете выбрать и запустить конкретные тесты.

### Запустить все тесты в headless режиме

```bash
npm run cypress:run
```

Это запустит все тесты в фоновом режиме без GUI.

### Запустить конкретный тест

```bash
npx cypress run --spec "cypress/e2e/header.cy.ts"
```

## Структура тестов

```
cypress/
├── e2e/                          # E2E тесты
│   ├── header.cy.ts              # Тесты навигации и хедера

│   ├── product-interaction.cy.ts # Тесты взаимодействия с товарами
│   └── forms-and-profile.cy.ts   # Тесты форм и профиля пользователя
├── support/                      # Вспомогательные файлы
│   ├── commands.ts               # Пользовательские команды
│   ├── component.ts              # Настройки компонентного тестирования
│   └── e2e.ts                    # Настройки E2E тестирования
├── tsconfig.json                 # TypeScript конфигурация для Cypress
└── fixtures/                     # Фикстуры для тестовых данных

```

## Пользовательские команды

В файле `cypress/support/commands.ts` определены следующие команды:

### `cy.login(email, password)`

Выполняет вход пользователя в систему.

```typescript
cy.login("user@example.com", "password123");
```

### `cy.logout()`

Выполняет выход пользователя из системы.

```typescript
cy.logout();
```

### `cy.addToCart(productId)`

Добавляет товар в корзину.

```typescript
cy.addToCart("iphone-15-pro");
```

## Добавление data-cy атрибутов

Для надежного тестирования рекомендуется добавить `data-cy` атрибуты к ключевым элементам:

```tsx
// Пример в Header компоненте
<div data-cy="cart-icon">
  <CartIcon />
</div>

// Пример в форме
<button data-cy="submit-button" type="submit">
  Отправить
</button>
```

## Рекомендации по написанию тестов

1. **Используйте data-cy атрибуты** вместо CSS классов для селекторов
2. **Избегайте хардкода задержек** - используйте `cy.wait('@alias')`
3. **Группируйте связанные тесты** в `describe` блоки
4. **Очищайте состояние** между тестами с помощью `beforeEach`
5. **Используйте `cy.intercept`** для мокирования API запросов
6. **Тестируйте user flows**, а не отдельные компоненты

## Debugging

### Открыть Chrome DevTools во время теста

```javascript
cy.debug();
```

### Сделать паузу в выполнении теста

```javascript
cy.pause();
```

### Вывести лог в консоль

```javascript
cy.log("Current step: checking cart");
```

## CI/CD Integration

Для запуска тестов в CI/CD pipeline используйте:

```yaml
# Пример для GitHub Actions
- name: Run Cypress tests
  run: npm run cypress:run
```

## Известные проблемы

1. **TypeScript ошибки**: После установки Cypress ошибки в файлах `*.cy.ts` должны исчезнуть
2. **baseUrl**: Убедитесь, что приложение запущено на `http://localhost:3000` перед запуском тестов
3. **Мокирование API**: Некоторые тесты используют `cy.intercept()` - при реальном API может потребоваться корректировка
